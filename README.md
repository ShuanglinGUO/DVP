# DVP
Dual-variable and position (DVP) method for computing the dispersion curves of guided waves propagation in multi-layered anisotropic composite plate.

# Description
DVP is a matrix-based method with recursive algorithm for computing the dispersion curves of guided waves propagation in multi-layered anisotropic composite plate, which is unconditionally stable. Two examples are provided here to demonstrate how to use this method. The two examples are from one paper under review. The complete source code of this repository will be available after the acceptance of the paper.
